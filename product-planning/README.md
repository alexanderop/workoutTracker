# Product Planning

This folder contains product planning artifacts for the Workout Tracker app. Use Claude to help with PO/BA tasks by referencing these files.

## Folder Structure

```
product-planning/
├── backlog/           # User stories, epics, and backlog items
├── templates/         # Reusable templates for various documents
├── roadmap/           # Product roadmap and release planning
├── personas/          # User personas and target audience
└── discovery/         # Research, interviews, competitive analysis
```

## Quick Start with Claude

Ask Claude things like:
- "Read the product vision and help me write user stories for [feature]"
- "Review the backlog and help me prioritize items"
- "Create a PRD for [feature] using our template"
- "Help me refine the acceptance criteria for story X"
- "Analyze our personas and suggest features that would benefit them"

## Files to Maintain

1. **PRODUCT_VISION.md** - Keep this updated as your north star
2. **backlog/BACKLOG.md** - Your prioritized list of work
3. **personas/** - User personas to guide decisions
4. **roadmap/ROADMAP.md** - High-level timeline and milestones
