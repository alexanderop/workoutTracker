### Fix 1: benchmarkHelpers.ts import error (2026-01-18)
**Tests fixed:** 5 test suites (benchmark-execution, benchmark-management, benchmark-results, benchmark-ui, benchmark-ux-simplification)

**Issue:** `benchmarkHelpers.ts` imported `userEvent` directly from `vitest/browser`:
```ts
import { userEvent } from 'vitest/browser'
```
This import fails in Happy-DOM mode because `vitest/browser` can only be imported in Browser Mode.

**Fix:** Changed to use the project's abstraction layer which auto-detects the environment:
```ts
import { page, userEvent } from '../../helpers/locator'
```

**Verification:** All benchmark test suites now load correctly in both Happy-DOM and browser mode.
