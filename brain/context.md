# Context

Project domain glossary. Grown by `grill` as terms are resolved. One term per definition; split large domains into `context/<area>.md` notes linked from here.

**Habit view mode** — which of three interchangeable layouts `/habits` renders
the same habits in: `grid` (3-up tiles), `rows` (compact rows with a date
header), or `cards` (large cards). A per-user preference persisted as the
`habitViewMode` user-setting key, defaulting to `cards`. Not a filter — every
habit appears in every mode; only the layout changes.
