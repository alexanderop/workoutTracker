📋 Prerequisites

Before you begin, ensure you have:

  • Node.js - Version ^20.19.0 or ≥22.12.0
  • pnpm - Version 10.24.0 or higher
  • Git - For cloning the repository

Check your versions:

node -v    # Should show v20.19+ or v22.12+
pnpm -v    # Should show 10.24+

⚠️ Don't have these installed? Get Node.js from nodejs.org and install pnpm with npm install -g pnpm

🚀 Setup Walkthrough

Step-by-step from clone to first run:

1. Clone the Repository

git clone <repository-url>
cd workoutTracker

2. Install Dependencies

pnpm install

This installs all packages defined in package.json. Takes ~1-2 minutes.

3. Start Development Server

pnpm dev

Vite starts a dev server with hot module replacement (HMR).

4. Open in Browser

Navigate to http://localhost:5173 in your browser. You should see the workout tracker app running!

💡 Common Issues:

  • Port 5173 in use? Vite will auto-select another port (check console)
  • Module errors? Delete node_modules/ and run pnpm install again
  • TypeScript errors? Ensure you're using Node.js version from prerequisites

🎯 Your First Contribution

Ready to make a change? Follow this workflow:

1. Make a Small Change

Example: Update a text label in a component or add a new exercise to the library.

// Example: Edit src/features/exercises/components/ExerciseCard.vue
// Change a label or add a new prop

2. Run Quality Checks

Before committing, ensure all checks pass:

  • pnpm type-check - TypeScript validation (strict mode, no any)

  • pnpm lint - Auto-fix with oxlint + ESLint

  • pnpm test - Run all tests (Playwright browser mode)

⚡ Quick check: Run all three at once with pnpm type-check && pnpm lint && pnpm test

3. Create a Branch & Commit

# Create feature branch
git checkout -b feature/my-awesome-change

# Stage your changes
git add .

# Commit with conventional format
git commit -m "feat(exercises): add new exercise card layout"

Commit format: type(scope): description

  • Types: feat, fix, refactor, test, docs, chore
  • Scopes: workout, exercises, templates, benchmarks, db, etc.

4. Push & Open PR

# Push to remote
git push -u origin feature/my-awesome-change

# Open a pull request on GitHub
# Describe what changed and why

🎉 Congratulations! You've made your first contribution. Check the Development page for detailed commit guidelines and code style requirements.
