Overview

A Vue 3 Progressive Web App for tracking strength and CrossFit workouts with offline-first capabilities. Built with modern tooling and strict TypeScript.

🚀 Quick Start

pnpm install
pnpm dev

Essential Commands:

  • pnpm test - Run all tests (Playwright browser mode)
  • pnpm type-check - TypeScript validation
  • pnpm lint - Auto-fix with oxlint + ESLint
  • pnpm build - Production build with type-check

💡 First time here? Check out Getting Started for a complete onboarding guide, then explore: Architecture → Features → Testing → Development.

🎯 Key Principles

  • 📦 Bulletproof Architecture - ESLint-enforced feature boundaries (Views → Features → Shared)
  • 🔒 Type Safety - Strict TypeScript with NO any, enum, or type assertions
  • 🧪 Integration-First Testing - Full user flows with real browser (Playwright mode)
  • 💾 Offline-First - Repository pattern with Dexie + IndexedDB for local data
  • 🎨 Modern Vue 3.5+ - Reactive props destructuring, defineModel, useTemplateRef
