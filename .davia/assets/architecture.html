Architecture

Architectural patterns and design principles that structure this Vue 3 PWA for scalability and maintainability.

📐 Core Architectural Patterns

This application follows proven architectural patterns for scalability and maintainability:

  • Bulletproof Feature-Based Architecture - ESLint-enforced dependency boundaries
  • Repository Pattern - Database abstraction layer with Dexie + IndexedDB
  • Singleton Composable Pattern - Shared reactive state across components
  • Block-Based Domain Model - Discriminated unions for workout types
