Testing Strategy

Comprehensive testing using Vitest with Playwright browser mode for real DOM and navigation.

🧪 Three-Tiered Testing Pyramid

  • Integration Tests (Top Priority) - Full user journeys with real routing and state
  • Composable Tests (Unit Tests) - Reactive logic with lifecycle support
  • Test Factories (Supporting) - Builder pattern for generating test data

🎯 Why Playwright Browser Mode?

Tests run in a REAL browser (not jsdom), giving access to:

  • ✅ Real DOM APIs (localStorage, IndexedDB, etc.)
  • ✅ Actual browser navigation and history
  • ✅ CSS and layout calculations
  • ✅ Web APIs like WakeLock for workout timers
  • ✅ Real user interactions (clicks, typing, focus)

🚀 Higher confidence: If it works in Playwright, it works in production.

📊 Test Coverage Goals

  • Integration tests - Cover all critical user flows (80%+ coverage)
  • Composable tests - Test complex reactive logic and state machines
  • Accessibility tests - Ensure screen reader compatibility
  • Browser API tests - Audio playback, wake lock, service worker

⚡ Testing Stack

  • Framework: Vitest 4 with Playwright browser mode
  • Rendering: Testing Library (Vue)
  • User simulation: @testing-library/user-event
  • Database: fake-indexeddb (for IndexedDB isolation)
  • Accessibility: axe-core integration

📁 Test Organization

src/__tests__/
├── integration/       # Full user flow tests ⭐
├── composables/       # Composable unit tests

✅ Essential Practices

1️⃣ Always Reset Database

import { resetDatabase } from '@/__tests__/setup'

beforeEach(async () => {
  await resetDatabase()  // ✅ Prevents test interference
})

2️⃣ Always Cleanup Integration Tests

it('my test', async () => {
  const app = await createTestApp()
  // ... test code ...
  app.cleanup()  // ✅ Required - prevents memory leaks
})

3️⃣ Use Query Priority

  1. getByRole (best - accessible)
  2. getByLabelText (forms)
  3. getByPlaceholderText (forms)
  4. getByText (non-interactive)
  5. getByTestId (last resort)

// ✅ GOOD - accessible query
const button = app.getByRole('button', { name: /start workout/i })

// ❌ AVOID - test ID (only when necessary)
const element = app.getByTestId('workout-timer')

🏃 Running Tests

# All tests
pnpm test

# Watch mode
pnpm test:watch

# Headed browser (visible)
pnpm test:headed

# With coverage (aim for >80%)
pnpm test:coverage

# Specific file
pnpm test src/__tests__/integration/workout-flow.spec.ts
