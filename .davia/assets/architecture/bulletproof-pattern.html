Bulletproof Pattern

Feature-based architecture with ESLint-enforced dependency boundaries for scalable Vue 3 applications.

🏗️ Three-Layer Hierarchy

Views → Features → Shared

  • Views - Route-level pages that orchestrate features
  • Features - Self-contained business logic domains
  • Shared - Reusable utilities, components, composables, database layer

🚫 Critical Rule

Features CANNOT import other features - enforced by ESLint at build time

This ensures loose coupling and prevents circular dependencies.

📊 Visual Architecture

📂 Directory Structure

src/
├── views/           # Route pages (ActiveWorkout, ExerciseLibrary, etc.)
├── features/        # Business domains
│   ├── workout/     # Workout execution & state
│   ├── exercises/   # Exercise library CRUD
│   ├── templates/   # Template management
│   ├── benchmarks/  # Benchmark tracking
│   ├── settings/    # App settings
│   └── timers/      # Timer UI components
├── composables/     # Shared reactive logic
├── components/      # Reusable UI (shadcn-vue)
├── db/              # Database repositories (Dexie)
├── stores/          # Pinia stores (exercises, settings)
├── router/          # Vue Router with RouteNames
└── types/           # Shared TypeScript types

✅ Feature Module Structure

Each feature follows a consistent internal structure:

src/features/{feature}/
├── components/      # Feature-specific Vue components
├── composables/     # Feature-specific composables
├── lib/             # Feature utilities
└── state/           # Singleton state (if needed)

🎯 Import Rules

  • ✅ Features → Shared imports are allowed
  • ❌ Features → Features imports are forbidden (ESLint enforced)
  • ✅ Views → Features imports orchestrate features
  • ✅ Views → Shared imports are allowed

💡 Benefits

  • Scalability - Add new features without affecting others
  • Maintainability - Clear boundaries prevent spaghetti code
  • Testability - Features can be tested in isolation
  • Team Collaboration - Multiple developers work independently
  • Code Reuse - Shared resources accessible to all features
