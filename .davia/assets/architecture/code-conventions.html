Code Conventions

TypeScript strict mode, Vue 3.5+ APIs, and ESLint-enforced patterns for consistent, maintainable code.

⚡ TypeScript Rules

  • ✅ Strict mode enabled - No escape hatches
  • ❌ NO any - Use unknown + type guards instead
  • ❌ NO enum - Use const objects or union types
  • ❌ NO type assertions (as T) - Let TypeScript infer
  • ✅ Use type over interface
  • ✅ Use Array<T> over T[]

// ❌ BAD
const data: any = response.data
const items = data as Item[]

// ✅ GOOD
const data: unknown = response.data
if (isItemArray(data)) {
  const items: Array<Item> = data
}

🎨 Vue 3.5+ Required APIs

1️⃣ Reactive Props Destructuring

// ✅ GOOD - Destructure with defaults
const { count = 0, isActive = false } = defineProps<{
  count?: number
  isActive?: boolean
}>()

// ⚠️ For watchers, wrap in getter
watch(() => count, (newCount) => {
  console.log('Count changed:', newCount)
})

2️⃣ Two-Way Binding with defineModel

// ✅ GOOD - Use defineModel for v-model
const open = defineModel<boolean>('open', { required: true })

function closeDialog() {
  open.value = false // Updates parent automatically
}

3️⃣ Template Refs

<script setup lang="ts">
import { useTemplateRef, onMounted } from 'vue'

const inputRef = useTemplateRef('input')

onMounted(() => {
  inputRef.value?.focus()
})
</script>

<template>
  <input ref="input" />
</template>

🔒 ESLint-Enforced Patterns

1️⃣ Error Handling: Use tryCatch()

import { tryCatch } from '@/lib/tryCatch'

// ✅ GOOD
const [error, workout] = await tryCatch(
  workoutRepository.getById(id)
)
if (error) {
  console.error('Failed to load:', error)
  return
}

// ❌ BAD - ESLint will error
try {
  const workout = await workoutRepository.getById(id)
} catch (error) {
  console.error(error)
}

2️⃣ Routing: Use RouteNames

import { RouteNames } from '@/router'

// ✅ GOOD
router.push({ name: RouteNames.WorkoutDetail, params: { id } })

// ❌ BAD - ESLint will error
router.push('/workout/' + id)

3️⃣ Import Boundaries

// ✅ GOOD - Feature imports from shared
import { useRestTimer } from '@/composables/timers/useRestTimer'
import { getWorkoutsRepository } from '@/db'

// ❌ BAD - Cross-feature import (ESLint will error)
import { useTemplateForm } from '@/features/templates/composables/useTemplateForm'

🎯 Common Patterns

Block-Based Workout Model

Use discriminated unions via kind property:

type WorkoutBlock = StrengthBlock | AmrapBlock | EmomBlock | TabataBlock | ForTimeBlock

type StrengthBlock = {
  kind: 'strength'  // Discriminator
  id: number
  exerciseName: string
  sets: Array<Set>
}

// Type guard
function isStrengthBlock(block: WorkoutBlock): block is StrengthBlock {
  return block.kind === 'strength'
}

Singleton Composable State

Share reactive state across components:

// Singleton ref defined once
const workout = ref<Workout>(createEmptyWorkout())

export function useWorkout() {
  return {
    workout,  // Shared ref - all components see same state
    selectBlock,
    removeBlock,
  }
}

🚫 Don'ts

  • Never modify shadcn-vue components in src/components/ui/

  • Never use native try/catch - use tryCatch()

  • Never use string literals for routes - use RouteNames

  • Never import across features - only from shared

  • Never commit without running pnpm lint && pnpm type-check
