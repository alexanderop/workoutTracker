Testing

Comprehensive testing strategy using Vitest + Playwright browser mode with integration-first approach.

🧪 Testing Philosophy

This project follows integration-first testing with Testing Library principles:

  • Test user behavior, not implementation details
  • Use accessible queries (getByRole, getByLabelText) over test IDs
  • Real browser environment via Playwright (NOT jsdom)
  • High confidence through full user journeys

🎯 Test Types

The project uses 6 distinct test types, each serving a specific purpose:

⚡ Quick Commands

# Run all tests (Playwright browser mode)
pnpm test

# Watch mode (auto-rerun on changes)
pnpm test:watch

# Headed browser (visible for debugging)
pnpm test:headed

# Interactive UI
pnpm test:ui

# Coverage report
pnpm test:coverage

📖 Testing Topics

Explore each testing approach:
