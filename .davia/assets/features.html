✨ Core Features

The application is organized into self-contained feature modules following Bulletproof architecture:

📖 Feature Documentation

Learn about each feature domain:

  • Workout Execution - State machines, timer logic, and workout types
  • Exercise Library - CRUD operations for custom exercises
  • Templates & Benchmarks - Save and reuse workout configurations

🎯 Feature Isolation

Each feature is self-contained with its own:

  • 📁 components/ - Feature-specific Vue components
  • 🎨 composables/ - Feature-specific reactive logic
  • 🔧 lib/ - Feature utilities (if needed)
  • 📦 state/ - Singleton state (if needed)

💡 Features communicate only through shared resources (stores, database, composables) - never by importing each other directly.
