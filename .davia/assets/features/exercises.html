Exercise Library

Build a personalized database of exercises you perform regularly. Makes workout creation faster and more consistent. 📚

💡 Why Use the Exercise Library?

Instead of typing exercise details every time you create a workout:

  • Save once, reuse forever: Define "Barbell Back Squat" with all details
  • Consistency: Same name, equipment, and defaults every time
  • Speed: Quick-add exercises to strength blocks in one tap
  • Organization: Browse your exercise collection, edit or delete as needed

🔄 Exercise Library Workflow

How exercises flow from library to workouts:

📝 Creating an Exercise

When adding a new exercise, you define:

  1. Name: e.g., "Barbell Back Squat", "Dumbbell Bench Press"
  2. Equipment: e.g., "Barbell", "Dumbbells", "Bodyweight", "Kettlebell"
  3. Target Reps: Default rep range (e.g., 5 for heavy compounds, 10 for accessories)
  4. Image/Icon: Optional thumbnail for quick visual identification

Example Exercise Definition:

Name: Barbell Back Squat

Equipment: Barbell

Target Reps: 5

Icon: 🏋️ Barbell icon

🎯 Using Exercises in Workouts

When building a workout with strength blocks:

  1. Add a Strength Block
  2. Choose "Select from Library"
  3. Pick an exercise (e.g., "Barbell Back Squat")
  4. Exercise details auto-fill:
    • Name → pre-filled
    • Equipment → pre-filled
    • Target Reps → pre-filled (editable for this workout)
  5. Add sets with weight/reps/RIR

Editing exercise details in the workout does NOT change the library definition.

✏️ Managing Your Library

Edit Exercise

  • Update name, equipment, target reps, or image
  • Changes apply to future uses (not retroactive to past workouts)

Delete Exercise

  • Removes from library permanently
  • Does NOT affect completed workouts that used this exercise
  • You'll need to manually type details if you want to use it again

💡 Best Practices

  • Add staples first: Main compound lifts (Squat, Bench, Deadlift, etc.)
  • Use consistent naming: "Barbell Back Squat" not "Back Squats" or "BB Squat"
  • Set realistic target reps: What you usually program (can override per workout)
  • Add images: Visual cues speed up exercise selection in the builder

🔗 Connection to Timed Blocks

Note: The exercise library is primarily for strength blocks. Timed blocks (AMRAP, EMOM, etc.) use simplified "BlockExercise" definitions that you create on-the-fly within the block itself.

This keeps timed blocks lightweight and focused on movement patterns rather than detailed strength tracking.
