Development

Developer workflow and contribution guide for maintaining code quality and consistency.

💡 New to the project? Start with the Overview page for installation and quick start commands.

✅ Definition of Done

Before creating a PR, ensure ALL of these pass:

  • pnpm type-check passes (no TypeScript errors)

  • pnpm lint passes (oxlint + eslint)

  • pnpm test passes (all tests green)

  • No any, enum, or type assertions added

  • No cross-feature imports (ESLint catches this)

  • shadcn-vue components in src/components/ui/ not modified

  • Followed Vue 3.5+ APIs (defineProps destructuring, defineModel, useTemplateRef)

💡 Quick check: pnpm type-check && pnpm lint && pnpm test

📝 Commit Format

Conventional Commits with scope:

feat(workout): add rest timer
fix(exercises): correct validation logic
refactor(db): simplify repository pattern
test(integration): add benchmark flow test
docs(readme): update setup instructions
chore(deps): upgrade vue to 3.5.1

Types: feat, fix, refactor, test, docs, chore

Run before committing:

pnpm lint && pnpm type-check

🌿 Branch Strategy

  • Main branch: main
  • Feature branches: feature/description or descriptive names
  • Check git status output for current branch name

🔒 Security & Secrets

  • ❌ Never commit tokens, API keys, or credentials
  • ✅ Environment variables: Use .env.local (gitignored)
  • ✅ No PII tracking: App is fully local (IndexedDB only)

🧪 Testing Workflow

# Run all tests
pnpm test

# Watch mode (auto-rerun on changes)
pnpm test:watch

# Headed browser (visible window for debugging)
pnpm test:headed

# Coverage report (aim for >80%)
pnpm test:coverage

# Run specific test file
pnpm test src/__tests__/integration/workout-flow.spec.ts

📦 Building for Production

# Production build (includes type-check)
pnpm build

# Preview production build locally
pnpm preview

The build output will be in dist/ directory.

🔍 Code Quality Tools

  • Type checking: pnpm type-check (TypeScript strict mode)
  • Linting: pnpm lint (oxlint + ESLint with auto-fix)
  • Unused code: pnpm knip (find unused exports/dependencies)
  • Testing: pnpm test (Vitest + Playwright browser mode)
