# Internationalization Design

## Overview

Add language support to the Workout Tracker PWA with English and German translations using vue-i18n v11 and TypeScript for type-safe translation keys.

## Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Languages | English + German | English default, German tests string length (+30%) |
| Architecture | Domain-split TypeScript | Matches component organization, maintainable |
| Loading | Lazy load per locale | Lean initial bundle for PWA |
| Storage | Settings store (IndexedDB) | Consistent with other app settings |
| Detection | Browser auto-detect first | Better first-run UX, then user override |
| Formatting | Update existing formatters | Less disruption, keeps current API |

## Implementation Details

### i18n Setup

```typescript
// src/i18n/index.ts
import { createI18n } from 'vue-i18n'
import type { MessageSchema } from './types'

export type SupportedLocale = 'en' | 'de'

export const i18n = createI18n<[MessageSchema], SupportedLocale>({
  legacy: false,              // Composition API mode
  locale: 'en',               // overridden by settings
  fallbackLocale: 'en',
  messages: {}                // lazy loaded
})

export async function loadLocale(locale: SupportedLocale) {
  if (i18n.global.availableLocales.includes(locale)) {
    i18n.global.locale.value = locale
    return
  }

  const messages = await import(`./messages/${locale}/index.ts`)
  i18n.global.setLocaleMessage(locale, messages.default)
  i18n.global.locale.value = locale
}
```

### Language Composable

```typescript
// src/composables/useLanguage.ts
import { watch } from 'vue'
import { loadLocale, type SupportedLocale } from '@/i18n'
import { useSettingsStore } from '@/stores/settings'

function detectBrowserLocale(): SupportedLocale {
  const browserLang = navigator.language.split('-')[0]
  return browserLang === 'de' ? 'de' : 'en'
}

export function useLanguage() {
  const settings = useSettingsStore()

  // Auto-detect on first visit
  if (settings.language === undefined) {
    settings.language = detectBrowserLocale()
  }

  watch(
    () => settings.language,
    async (locale) => {
      await loadLocale(locale)
      document.documentElement.lang = locale
    },
    { immediate: true }
  )

  function setLanguage(locale: SupportedLocale) {
    settings.language = locale
  }

  return {
    currentLanguage: () => settings.language,
    setLanguage
  }
}
```

### Locale-Aware Formatters

```typescript
// src/lib/formatters.ts
import { i18n } from '@/i18n'

export function formatDate(timestamp: number): string {
  const locale = i18n.global.locale.value
  return new Date(timestamp).toLocaleDateString(locale, {
    month: 'short',
    day: 'numeric',
    year: 'numeric',
  })
}
```

## Migration Phases

### Phase 1: Foundation
1. Install `vue-i18n`
2. Create `src/i18n/` structure with English messages
3. Add `language` to settings store
4. Create `useLanguage` composable
5. Wire up in `main.ts` and `App.vue`
6. Update `formatters.ts` to be locale-aware

### Phase 2: Extract Strings (by priority)

| Priority | Area | Files | Reason |
|----------|------|-------|--------|
| 1 | `exerciseLabels.ts` | 1 | Already structured |
| 2 | Navigation | 1 | Visible everywhere |
| 3 | Settings view | 1 | Language selector home |
| 4 | Views | 11 | High visibility |
| 5 | Dialogs | 15 | Self-contained |
| 6 | Feature components | 60 | Bulk work |

### Phase 3: German Translations
Create `de/` mirror files after English extraction complete. Translate in batches by domain.
